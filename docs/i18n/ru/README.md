# Osmo360 Android Live Preview

Неофициальный прототип Android-приложения для live preview камеры DJI Osmo 360, потокового просмотра 360-градусной камеры, BLE-пробуждения, подключения к Wi-Fi камеры и локального H.264 preview.

**Языки:** [English](../../../README.md) | [中文](../zh-CN/README.md) | Русский

Проект предназначен для разработчиков, которые изучают подключение Osmo 360 к нативному Android-приложению. Пользователь может ввести SSID Wi-Fi камеры, пароль Wi-Fi, опциональное BLE-имя, опциональный BSSID/MAC и IP-адрес камеры прямо в приложении. Настройки сохраняются только локально на устройстве через Android `SharedPreferences`.

## Возможности

- Нативный Android-прототип live preview для Osmo 360
- Настройки подключения камеры внутри приложения
- Обнаружение и пробуждение через Bluetooth/BLE
- Подключение к Wi-Fi камеры через Android `WifiNetworkSpecifier`
- Локальный H.264 preview через Android `MediaCodec`
- Понятные состояния ошибок для Bluetooth, видимости Wi-Fi и обнаружения камеры
- Очищенная структура исходного кода для публикации на GitHub

## Сценарии использования

- Эксперименты с Osmo 360 Android live preview
- Исследование потокового видео с 360-градусной камеры на Android
- Прототипы Wi-Fi подключения камеры с BLE-поддержкой
- Локальные preview-приложения с H.264 и `MediaCodec`
- Неофициальное тестирование совместимости с камерами, которыми вы владеете или имеете право пользоваться

## Сборка

Откройте этот репозиторий в Android Studio и запустите конфигурацию `app`, либо соберите из терминала:

```bash
export ANDROID_HOME="$HOME/Library/Android/sdk"
./gradlew :app:assembleDebug
```

Debug APK создается здесь:

```text
app/build/outputs/apk/debug/
```

## Запуск

1. Установите и откройте `Osmo Preview`.
2. Включите Bluetooth.
3. Нажмите `Settings`.
4. Введите SSID Wi-Fi камеры и пароль.
5. При необходимости укажите BLE-имя и BSSID/MAC.
6. Оставьте IP камеры по умолчанию, если камера не использует другой адрес.
7. Подтвердите, что вы владеете камерой или имеете разрешение на подключение.
8. Сохраните настройки, вернитесь на главный экран и нажмите `Start Osmo Preview`.

Если Wi-Fi камеры не виден, приложение сначала попытается выполнить BLE-пробуждение и может определить фактический SSID Wi-Fi камеры во время обнаружения.
